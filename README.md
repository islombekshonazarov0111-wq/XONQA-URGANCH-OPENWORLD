# Xonqa–Urganch Open World — foundation

Mobile-first Godot 4.7.x project.

Locked design rules:
- Open world: Xonqa ↔ Urganch corridor
- Streaming chunks; whole map is never kept loaded
- No real-time shadows
- Persistent FPS counter
- Graphics presets + custom settings architecture
- Circular touch steering
- Per-car vehicle data; automatic P/R/N/D where appropriate
- Manual gearbox reserved for manual cars
- Per-vehicle engine/audio banks planned
- Player on-foot / enter-exit vehicle foundation
- Nightclub is a separate streamed interior scene
- Traffic pooling and real map assets are next production layers

Important:
This ZIP is the engineering foundation, not a claim that real Xonqa/Urganch geometry,
licensed car models, or recorded vehicle sounds are already included.
